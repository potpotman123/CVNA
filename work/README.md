# Research outputs and local source materials

Analytical notes, calculations, models, charts and source manifests are shared in Git. Raw downloads, licensed sellside reports and transcript text, browser captures, temporary files and large source archives remain local and are excluded by `.gitignore`.

Start with [the research handoff](../CVNA-RESEARCH-HANDOFF-2026-10-31.md). Its source links describe the original local workspace; some intentionally refer to files not distributed in this repository. Source manifests, evidence ledgers and original URLs identify the inputs. Obtain licensed inputs through your own authorized access. Reproduction scripts may require those local inputs and dependencies; a fresh clone is not a complete source-data bundle.

The expanded sellside manifest maps numbered local PDFs to original filenames, archive provenance and hashes. Its report catalog provides screening notes without redistributing the reports themselves.
