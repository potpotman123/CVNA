# Collaboration and research persistence

- User preference, October 31, 2026: completed research work should eventually be committed and pushed to the CVNA Git repository so collaborators can access it. Do not leave completed deliverables only in the local workspace.
- Preserve unrelated and in-progress work. Commit coherent research outputs, supporting calculations, source manifests and handoffs; verify the intended remote/branch and push without force.
- Keep licensed reports/transcript text, raw browser captures, temporary files and large source downloads out of Git by default. Preserve provenance and explain source dependencies for collaborators.
- Distinguish measured evidence, assumptions and unresolved questions. Read the current research handoff and relevant evidence files before repeating prior searches.
